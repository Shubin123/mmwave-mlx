mmWave-Dataset · MLX · WebGPU

Seeing forklifts and robots with radar

An indoor-logistics radar dataset, synchronized with Vicon motion capture. A PointNet trained with MLX reads each radar scan and says what is in the room, where it is and which way it faces. It runs right here in your browser on the GPU, and falls back to CPU workers.

Explore the recordings

23 recordings, 4 objects, about 34k radar frames at 5 Hz. Pick one. The model scores every frame up front in a single batch, then the playback shows its predictions next to the Vicon ground truth.

The model

Each input is the radar returns from the current frame plus the two before it (age is a feature), capped at the 256 strongest by SNR. A shared per-point MLP lifts every return to 256 features, a max-pool makes it order-invariant, and a small head predicts four things at once.

How to read these numbers. Each recording is split in time: the first 70% is for training, then 15% validation, then 15% test, with a gap so no window spans two splits. In the static recordings the object never moves, so their near-perfect pose scores mostly show that the model recognizes the scene. The moving recordings are the real localization test, because their test segments reach positions and headings the model saw less of in training.

Throughput in your browser

The WebGPU backend runs the whole network as one fused compute shader. Each workgroup handles one frame window, and points stream through workgroup memory 16 at a time, so per-point activations never reach VRAM and padding never gets computed. Without WebGPU, the same math runs on a pool of Web Workers.

Reproduce

git clone https://github.com/Shubin123/mmwave-mlx && cd mmwave-mlx
uv venv -p 3.12 && uv pip install -r requirements.txt
python -m mmwave.prep          # downloads the 23 synchronized CSVs (~215 MB) from Kaggle
python -m mmwave.train         # ~4 min on an M-series Mac
python -m mmwave.export        # writes docs/model and docs/data
node tests/parity.mjs          # JS kernel vs MLX outputs
python -m http.server -d docs  # open http://localhost:8000
